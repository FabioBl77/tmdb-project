# TMDB Project

Applicazione dedicata alla consultazione di film e contenuti tramite TMDB, The Movie Database.

Il progetto permette di cercare film, visualizzare informazioni principali e lavorare con dati provenienti dall'API di TMDB, come titoli, descrizioni, immagini, valutazioni e altri dettagli disponibili.

## Funzionalita

- Ricerca di film tramite TMDB
- Visualizzazione delle informazioni principali dei film
- Recupero dei dati da API esterne
- Organizzazione del progetto per lo sviluppo di una web app dedicata al catalogo cinematografico

## Tecnologie

Il progetto utilizza tecnologie web e integrazione con l'API di TMDB.

## Configurazione

Per usare il progetto e' necessario avere una API key di TMDB.

1. Crea un account su TMDB
2. Vai nelle impostazioni sviluppatore
3. Genera una API key
4. Inserisci la chiave nel progetto secondo la configurazione prevista
